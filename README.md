# Scrap News — новости Scrap Mechanic на русском

Неофициальный фанатский сайт с новостями, патчами и обновлениями игры **Scrap Mechanic**,
оформленный в стиле Steam. Новости подтягиваются из Steam автоматически и переводятся
на русский язык.

**Адрес сайта:** https://maxfixglitch.github.io/ScrapMecanicNowosti/

Репозиторий: https://github.com/MaxfixGlitch/ScrapMecanicNowosti

---

## Как это работает

Сайт полностью статический — это обычные `index.html` + CSS + JS, без сборки и без сервера.
Данные лежат в папке `data/`:

| Файл | Что внутри |
|---|---|
| `data/news.json` | новости из Steam (заголовок, текст, дата, картинки, ссылка на оригинал) |
| `data/game.json` | карточка игры: описание, обложка, жанры, дата выхода, цена, онлайн |
| `data/manual-news.json` | ваши собственные записи, которых нет в Steam |
| `data/translations.json` | вручную вычитанные переводы (приоритетнее авто-перевода) |

Файлы `news.json` и `game.json` обновляет **GitHub Actions** (`.github/workflows/update-news.yml`):

* запускается автоматически **каждые 6 часов**, а также при изменении скриптов;
* можно запустить вручную: вкладка **Actions** → «Обновление новостей Scrap Mechanic» → **Run workflow**;
* забирает новости через `ISteamNews/GetNewsForApp` (appid `387990`) и карточку игры
  через Steam Store API с локализацией `l=russian`;
* переводит заголовки и тексты на русский (сначала ручные переводы из `translations.json`,
  затем авто-перевод; если перевод не удался — остаётся оригинал и ставится метка
  «Оригинал на английском»);
* складывает новые записи в архив, поэтому старые новости не пропадают.

Никаких ключей API и секретов не требуется.

## Запуск локально

Нужен только статический сервер (иначе браузер не даст прочитать `data/*.json`):

```bash
cd ScrapMecanicNowosti
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Как добавить или поправить новость

### Своя запись, которой нет в Steam

Откройте `data/manual-news.json` и добавьте объект в массив `items`:

```json
{
  "title": "Заголовок новости",
  "body": "<p>Текст в HTML.</p><ul><li>Можно списки</li><li>и картинки: <img src=\"...\"></li></ul>",
  "date": 1793294058,
  "author": "Подпись автора",
  "feedlabel": "Ручная запись",
  "feedlabel_ru": "Ручная запись",
  "tags": ["Новость"],
  "translated": true,
  "url": ""
}
```

`date` — это Unix-время в секундах. Узнать текущее можно командой `date +%s`.

### Поправить авто-перевод

Если машинный перевод где-то смотрится криво, откройте `data/translations.json`
и добавьте по `gid` новости (его видно в адресе поста на сайте: `#p-<gid>`) свой вариант:

```json
{
  "items": {
    "1847920302235687": {
      "title": "Патч 1.0.7 (тестовая ветка)",
      "body": "<p>Привет, механики! ...</p>"
    }
  }
}
```

После сохранения запустится GitHub Actions и применит ваш перевод.

## Настройки

Переменные окружения в воркфлоу (файл `.github/workflows/update-news.yml`):

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `SM_APPID` | `387990` | AppID игры в Steam |
| `SM_TRANSLATE_LIMIT` | `30` | сколько новых постов переводить за один запуск |
| `SM_MAX_ITEMS` | `400` | максимум записей в архиве |
| `SM_DEBUG` | `0` | `1` — подробные логи |

## Публикация (GitHub Pages)

1. В репозитории: **Settings → Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: `main`, папка `/ (root)` → **Save**.

Через пару минут сайт будет доступен по адресу
`https://maxfixglitch.github.io/ScrapMecanicNowosti/`.

> Пока изменения не слиты в `main`, сайт опубликован из рабочей ветки.
> После merge переключите источник Pages на `main`.

## Структура

```
index.html                  разметка страницы
assets/css/steam.css        оформление «под Steam»
assets/js/app.js            лента, фильтры, поиск, живое обновление из Steam
assets/img/favicon.svg      иконка
scripts/update_data.py      сборщик данных из Steam (запускается в Actions)
data/news.json              новости (генерируется)
data/game.json              карточка игры (генерируется)
data/manual-news.json       свои записи
data/translations.json      ручные переводы
.github/workflows/update-news.yml
```
