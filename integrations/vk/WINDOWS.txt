УСТАНОВКА БОТА SCRAPMEHI НА WINDOWS 11

Это не программа, которая должна постоянно работать на компьютере.
Установщик один раз загрузит бота в Cloudflare; потом компьютер можно выключать.
GitHub и доступ к репозиторию для установки не нужны.

ПЕРЕД НАЧАЛОМ

В вашем аккаунте Cloudflare уже должны быть:
  - приложение scrapmehi-news (пока Hello World);
  - секрет VK_TOKEN — ключ сообщества с правом доступа к стене;
  - секрет ADMIN_SECRET — отдельный случайный служебный пароль.
Никаких ключей в файлах архива нет. Установщик не просит их вводить.

1. Установите текущую LTS-версию Node.js с официального сайта:
   https://nodejs.org/
   Подойдёт Node.js 22 или новее, с компонентами npm и добавлением в PATH.
   Дополнительные средства сборки (Tools for Native Modules) не требуются.
   Если Node.js LTS уже установлен, повторная установка не нужна.

2. Распакуйте ВЕСЬ архив (правой кнопкой мыши по ZIP → Извлечь всё).
   Не запускайте установщик прямо из окна архива.
   Оставьте все файлы вместе в распакованной папке.

3. Откройте install-windows.cmd обычным двойным щелчком.
   Сообщения установщика теперь на английском, чтобы не зависеть от кодировки CMD.
   Continue? Y = yes, N = no — продолжить: Y, отменить: N.
   ERROR: Node.js 22 or newer — сначала установите Node.js LTS.
   ERROR: worker.mjs or wrangler.jsonc is missing — распакуйте весь архив.
   Запуск от имени администратора для самого установщика не нужен.
   Если защита Windows или антивирус выдаст предупреждение, не отключайте защиту:
   сначала покажите помощнику текст предупреждения.

4. Прочитайте описание действий. Для продолжения нажмите Y и Enter,
   для отмены — N. Если появится окно браузера от Cloudflare, проверьте,
   что открыт ваш правильный аккаунт, и подтвердите вход официальной
   утилите Wrangler. Если в браузере входите через GitHub, это допустимо:
   репозиторий к приложению не подключается.

5. Установщик загрузит код в существующее приложение scrapmehi-news,
   создаст память SQLite Durable Object и расписание раз в час.
   Вместо Hello World появится бот. Уже сохранённые секреты останутся.
   Может быть предупреждение о замене кода, ранее изменённого в панели:
   для заготовки Hello World это ожидаемо. Если приложение уже содержит
   какой-то другой важный код, не подтверждайте замену.

6. Дождитесь результата. Успешная загрузка НЕ доказывает, что ключ ВК работает.
   Запишите адрес вида https://scrapmehi-news....workers.dev из вывода.
   Дальше нужно проверить состояние бота вместе с помощником.
   Ключ ВК и ADMIN_SECRET помощнику не отправляйте.

ЧТО БУДЕТ ПУБЛИКОВАТЬСЯ

Первый успешный запуск только запомнит архив. Старые новости на стену не отправятся.
Затем новые русские новости будут выходить от имени сообщества scrapmehi:
заголовок, текст и ссылка на статью. В этой версии нет загрузки фото и видео.
Расписание проверяет сайт раз в час, но сам сайт обновляется примерно раз в 6 часов.
Запуск не обязательно начнётся сразу после установки: расписанию нужно примениться.

Если ВК вернёт ошибку отправки или оборвётся соединение, бот приостановит отправку,
чтобы избежать дублей. Причину и дальнейшие действия проверим отдельно.
Бот не редактирует уже опубликованные новости при обновлении исходного патча.

ВАЖНО

- Выберите бесплатный тариф Workers Free; платный тариф включать не нужно.
- Бесплатные лимиты и правила сервиса могут меняться.
- Не запускайте несколько копий бота для той же группы и не удаляйте его память.
- Не присылайте в чат ключи, пароли или ссылки подтверждения авторизации.
- Для временной остановки удалите Cron Trigger в настройках Worker.
- Для полной остановки отзовите ключ в ВК и удалите VK_TOKEN из Cloudflare.

Архив содержит открытый исходный код, конфигурацию и этот установщик.
Установщик скачивает официальную утилиту wrangler@4.168.0 из реестра npm
через npx, открывает вход в Cloudflare и выполняет deploy --keep-vars.
Он не настраивает автозапуск Windows и не сохраняет ключ ВК на компьютер.
Техническая инструкция и восстановление после ошибок — в README.md.

Проверки кода выполнены локально с имитацией ВК. Реальная публикация не проверена.
Установщик .cmd подготовлен для Windows, но из среды Linux на Windows не запускался.
